# Contributing

1. Create a focused branch from `main`.
2. Keep credentials and exported customer/order data out of commits.
3. Check changes against anonymised data before using the live databases.
4. Confirm the dashboard loads and the headline totals reconcile to Notion.
5. Explain the business reason and user-visible effect of the change.

Use conventional, concise commit messages such as `feat: add platform margin breakdown` or `fix: apply quantity to sold inventory cost`.
